# Directives pour l'agent (Claude Code)

Ce fichier est chargé automatiquement à chaque session, y compris en session
web/cloud. Il fixe des règles **opérationnelles** que l'agent doit suivre sans
qu'on ait à les redemander.

## Branches de travail

- **Jamais** livrer le travail sur la branche `claude/<aléatoire>` attribuée par
  défaut à la session. Ce nom est imposé par l'infrastructure, il ne décrit rien.
- Avant d'ouvrir une PR, (re)créer une branche **conforme à la convention du
  dépôt**, dérivée du dernier `origin/main` :
  - `release/X.Y.Z` — un bump de version (lockstep monas).
  - `fix/<slug>` — une correction.
  - `feat/<slug>` — une fonctionnalité.
  - `chore/<slug>` / `refactor/<slug>` — outillage, nettoyage, remaniement.

## Corps des pull requests

- L'intégration GitHub des sessions web **rajoute d'office** un pied de page
  `_Generated by [Claude Code](https://claude.ai/code/session_…)_` au corps des
  PR créées via l'outil MCP — **malgré** `attribution.sessionUrl: false` /
  `attribution.pr: ""` dans `.claude/settings.json` (ces réglages ne sont pas
  honorés pour les PR créées via MCP ; c'est un trou côté plateforme).
- **Toujours** retirer ce pied de page **immédiatement** après
  `create_pull_request` **et** après chaque `update_pull_request` (l'ajout est
  ré-appliqué à chaque écriture du corps) : relire le corps, réécrire sans la
  ligne.
- Ne mettre **aucune** mention du modèle ni de la session (liens `claude.ai`,
  identifiant de modèle) dans les artefacts poussés : commits, titres/corps de
  PR, code, commentaires. Cela reste dans le fil de discussion.
